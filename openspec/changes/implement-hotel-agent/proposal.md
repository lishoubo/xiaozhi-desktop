# 酒店 Agent 端到端能力

## 背景

桌面端已有 Agent 页面与 json-render 组件目录，但当前只展示 mock 内容，服务端也没有可持久化、可流式调用的大模型运行时。

## 目标

- 以 Kimi K3 为单 Agent 模型，通过现有 desktop → server tRPC 边界提供流式对话。
- 持久化会话、消息、可恢复事件和跨会话长期记忆。
- 支持可配置 MCP 工具、预留空 Skill registry，并允许模型产生受限的 json-render UI。
- 桌面端展示 token、执行步骤、工具调用、错误与生成式 UI，并提供酒店运营快捷任务。

## 非目标

- 不启用子 Agent。
- 不在本次实现尚未确定的业务 Skill。
- 不自动执行修改订单、价格、库存、支付等高风险酒店操作。

## 成功标准

- 已登录员工可创建/恢复会话并通过 tRPC SSE 收到按序流式事件。
- 刷新或重启后可读取历史消息；同一员工的新会话可召回其长期记忆。
- MCP 配置缺失时 Agent 仍可对话；配置存在时工具按白名单加载。
- 生成式 UI 只能使用共享允许的酒店组件，前端可安全渲染。
