## ADDED Requirements

### Requirement: 更新源地址随环境固化

系统 MUST 让每个环境有各自的更新源地址，并在构建期固化进产物，与既有的 RMS 地址、
server 地址同样处理——运行时读取会在双击启动的产物上静默兜底成错误配置。

更新源地址为空 MUST 表示「该环境不启用自动更新」，构建 MUST 继续且 MUST NOT 报错。
dev 与 pre 不分发给客户，没有更新源是这两个环境的正常状态；把它当成构建失败会让本地
开发无法打包。

更新源地址 MUST 独立于 RMS 地址与 server 地址取值。更新包托管在可匿名读取的公网位置，
与需要登录的业务服务端不是同一个系统，复用任一业务地址都会指向不存在的路径。

#### Scenario: online 产物

- **WHEN** 构建 online 产物
- **THEN** 产物中固化了 online 的更新源地址

#### Scenario: 未配置更新源的环境

- **WHEN** 构建 dev 或 pre 产物，其 profile 未配置更新源地址
- **THEN** 构建成功
- **AND** 产物不启用自动更新

#### Scenario: 运行时环境变量不影响已打包产物

- **WHEN** 已打包的应用在设置了更新源环境变量的 shell 中启动
- **THEN** 应用仍使用构建期固化的更新源地址
