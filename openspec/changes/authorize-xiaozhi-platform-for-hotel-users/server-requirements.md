# 给 RMS 项目的需求：酒店用户的小智平台个人授权

> 本文仅记录跨项目需求。实施位置为 `xiaozhi-rms-workspace`，本仓库不修改其代码。Desktop 对接以此文的可观察行为为准；RMS 内部数据表、管理入口和代码结构由 RMS 项目确定。

## 目标与现有接口

让**指定酒店用户**进入小智平台统一改价页，并且只能操作自己已获酒店访问权的酒店。不是 OSS 白名单，也不新增功能专属酒店名单。

Desktop 登录和恢复会话后调用 `GET /api/v1/me`。该接口现有字段足以承载结果：

| 字段 | 现有含义 | 本需求中的用途 |
|---|---|---|
| `userType` | `STAFF` / `HOTEL` | 区分服务商与酒店用户；不以 `role` 代替 |
| `role` | 角色码 | 保持原义，不用它判定个人授权 |
| `permissions` | 权限码数组，目前仅来自角色 | 合并个人授权后的**有效权限**；含 `xiaozhi:access` 表示获准使用小智平台 |
| `accessibleHotelIds` | 当前用户可访问酒店 ID 数组 | 直接复用；非空时酒店用户才显示入口，页面只在这些酒店中选择 |
| `currentHotelId` | 当前选择的酒店 | 必须仍受现有酒店访问校验约束 |

响应**不增加字段**，字段类型和空值语义保持现状。未获授权的酒店用户不得收到 `xiaozhi:access`；授权用户即使没有可访问酒店，也应如实返回该权限与空 `accessibleHotelIds`，由客户端同时判断两项。

## 服务端必须提供的行为

1. **个人级授予与撤销。** 管理员能够只给指定酒店用户授予或撤销 `xiaozhi:access`；不得通过给整个 `HOTEL_STAFF` 角色增加权限来实现。授予方式需可追踪操作人与时间，用户停用时授权不得继续生效。角色权限保持原义。
2. **`/me` 返回有效权限。** `permissions` 包含当前角色权限和当前用户仍有效的个人权限；登录后、恢复会话后及再次调用 `/me` 时结果一致。撤销后再次调用 `/me` 不再包含 `xiaozhi:access`。服务端接口校验必须使用与 `/me` 相同的有效权限口径，而非只按角色查询。
3. **酒店范围直接复用。** `accessibleHotelIds` 继续由现有酒店访问授权计算；酒店列表、选择当前酒店和业务请求仍按现有酒店访问规则过滤与校验。个人 `xiaozhi:access` 不改变用户可以访问的酒店，也不产生第二份酒店列表。
4. **页面与业务请求授权。** 对 `HOTEL` 用户，直接访问 `/unified-pricing` 和该页所需的业务接口时，必须校验 `xiaozhi:access` 以及所选酒店仍可访问。没有权限或没有可访问酒店时不得读取或提交该页业务数据。对 `STAFF` 用户保留现有访问与业务权限。授权被撤销或酒店访问权被收回后，后续业务请求应被拒绝，不能仅依赖桌面端隐藏 Tab。
5. **统一改价可实际使用。** 目前 `HOTEL_STAFF` 只有 `pricing:view`，统一改价的计算、提交、房态房量推送等接口要求 `pricing:write`。RMS 必须核对页面实际调用的接口，为获个人授权的酒店用户提供完成该页面读写流程所需的权限，同时避免无意授予其他改价功能的通用写权限；未授权用户仍被拒绝。实现可调整相关接口授权策略，但不得只改 `/me` 而留下“可见但无法操作”的状态。

## 验收场景

| 用户状态 | `/me.permissions` | `/me.accessibleHotelIds` | 预期 |
|---|---|---|---|
| 未授权酒店用户，有已授权酒店 | 不含 `xiaozhi:access` | 非空 | 小智平台入口不可见；直达页面/接口拒绝 |
| 已授权酒店用户，无已授权酒店 | 含 `xiaozhi:access` | 空 | 小智平台入口不可见；业务请求不能越权指定酒店 |
| 已授权酒店用户，有已授权酒店 | 含 `xiaozhi:access` | 非空 | 可进入页面并完成统一改价，仅能操作可访问酒店 |
| 已授权用户切换到无权酒店，或酒店授权被撤销 | 按当前个人授权返回 | 仅含仍可访问酒店 | 选择无权酒店失败；后续相关请求拒绝 |
| 个人授权被撤销 | 不再含 `xiaozhi:access` | 按酒店访问权返回 | 后续页面业务请求拒绝；重新取 `/me` 后 Desktop 收起入口 |
| 服务商用户 | 保持原有角色权限 | 按原有规则返回 | 原有小智平台行为不受影响 |
