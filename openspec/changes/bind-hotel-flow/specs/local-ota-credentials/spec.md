## MODIFIED Requirements

### Requirement: 本地只保存酒店信息，不表达绑定关系

本地酒店记录 MUST 只保存渠道酒店自身的信息：所属凭证、渠道、OTA 酒店 ID、酒店名称和
渠道原始上下文。OTA 酒店与 RMS 酒店之间的绑定关系 MUST NOT 保存在本地，该关系由远端
持有。本地记录 MUST NOT 引入表达绑定动作的字段（如绑定时刻、RMS 酒店标识）。

写入 MUST 只发生在用户确认绑定之后，且 MUST 在远端绑定成功之后——远端失败时不得写入
本地。

#### Scenario: 用户确认候选酒店

- **WHEN** 用户从候选列表中选定一家酒店并确认
- **AND** 远端绑定已成功
- **THEN** 系统保存该酒店的凭证标识、渠道、OTA 酒店 ID、酒店名称和渠道原始上下文
- **AND** 系统不在本地保存该酒店与任何 RMS 酒店的对应关系

#### Scenario: 远端绑定失败时不写本地

- **WHEN** 用户确认绑定但远端请求失败
- **THEN** 系统不写入本地酒店记录

#### Scenario: 查询本地酒店信息

- **WHEN** 系统按渠道与 OTA 酒店 ID 查询本地酒店记录
- **THEN** 返回结果只包含酒店自身信息与所属凭证标识
- **AND** 返回结果不包含绑定关系字段
